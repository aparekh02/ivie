The Poseidon degree wall

The in-AIR hash that commits the state tree is algebraic by design. That is also its one exploitable surface: eliminate its round system to a single polynomial and a preimage falls out by field arithmetic — until the algebraic degree 3r grows past reach. This is the map of exactly where that happens.

The attack, start to finish

No brute force. Each step is exact finite-field algebra over F_p, the same field the prover uses. The branch at the end is what makes it dangerous: a second preimage swaps a wallet value while the committed root never changes.

Where it dies: degree vs rounds

The elimination polynomial has degree 3r, so its log₂ grows a flat 1.585 bits per round. The attack is only feasible while that polynomial can be built and root-found; past the crypto floors it is strictly worse than a generic Grover preimage search.

XL / Macaulay: the solving degree

Keep the interior round states as variables and the preimage becomes a system of degree-3 equations. Linearizing it (the Gröbner-family XL algorithm) and reducing the Macaulay matrix recovers the same preimage — and names the solving degree D*, the quantity a round count is chosen to inflate.

QAOA on the same cost

A full statevector QAOA run over a windowed input, with a Hamming-distance cost between the candidate's hash and the target. The graded landscape lets the variational circuit concentrate amplitude on the preimage — a quantum read of the same structure the algebra exploits directly.
